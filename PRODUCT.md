# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Vite, and TypeScript, specified by the portfolio owner. Static deployment target: GitHub Pages.

## Users

Recruiters, hiring managers, and technical peers reviewing a Computer Science student's and IT & software professional's body of work.

## Product Purpose

Present a personal engineering portfolio as an editable archive of selected projects, with clear routes to project details and contact channels.

## Positioning

An engineering project archive rather than a generic developer-portfolio template; project evidence leads, while unprovided claims remain intentionally absent.

## Capabilities and Constraints

Four initial project records: Pordle.io, calpolyshpe/calpolyshpe.org, mattphanm/lpl-financial-team-34, and Meboy1000/Tic-Tac-Task. Project descriptions, features, results, contributions, and real profile links are deliberately undecided and must remain editable placeholders. The site must be static-site friendly and deployable to GitHub Pages at no cost.

## Evidence on Hand

Project names only. No verified project descriptions, links, media, outcomes, skills, bio, resume, or contact details were supplied; future work must not fabricate them.

## Product Principles

- Let the project archive be the primary artifact.
- Keep all editable portfolio facts centralized.
- Favor direct, accessible navigation and readable project detail.
- Treat unknown facts as clear placeholders, never as claims.

## Accessibility & Inclusion

Semantic landmarks, keyboard navigation, visible focus, reduced-motion support, and sufficient text contrast are required.
